# Koemmerle at Home v0.5.0

Release notes for changes between `v0.4.0` and `v0.5.0`.

## English

### Highlights

- Added ready-to-run release builds for Windows and Linux, alongside the existing macOS release flow.
- Improved release automation with expanded GitHub Release packaging and fixed release-build handling.
- Refactored Migros HTTP session handling for better cross-platform support, including Windows compatibility.
- Improved Playwright login/session handling and made Migros header capture and HTTP/2 behavior more configurable.
- Improved sticker-page handling with persisted state, better GTIN search behavior, toast notifications, and a hidden seasonal mini-game.

### Details

- Added publish scripts for Linux and Windows, plus shared version-sync tooling.
- Updated release documentation with macOS, Linux, and Windows build/run instructions.
- Added startup handling for packaged macOS builds and first-run Playwright browser setup improvements.
- Added an interactive sticker mini-game with custom product sprites, delivery scene assets, scoring, controls, and chiptune audio refinements.
- Updated backend, frontend, and root version metadata from `0.4.0` to `0.5.0`.

Compared tags: `v0.4.0..v0.5.0`

## Deutsch

### Highlights

- Fertige Release-Builds für Windows und Linux wurden ergänzt, zusätzlich zum bestehenden macOS-Release.
- Die Release-Automation wurde erweitert, inklusive GitHub-Release-Paketen und korrigiertem Release-Build.
- Die Migros-HTTP-Session wurde für bessere Plattformunterstützung überarbeitet, inklusive Windows-Kompatibilität.
- Playwright-Login und Session-Handling wurden verbessert; Header-Erfassung und HTTP/2-Verhalten sind nun konfigurierbarer.
- Die Sticker-Seite wurde verbessert mit gespeichertem Zustand, besserer GTIN-Suche, Toast-Meldungen und einem versteckten saisonalen Mini-Spiel.

### Details

- Publish-Skripte für Linux und Windows sowie gemeinsame Version-Sync-Werkzeuge wurden ergänzt.
- Die Release-Dokumentation enthält nun Build- und Startanleitungen für macOS, Linux und Windows.
- Paketierte macOS-Builds starten robuster; Playwright-Browser werden beim ersten Start besser vorbereitet.
- Ein interaktives Sticker-Mini-Spiel wurde ergänzt, inklusive Produktsprites, Liefer-Szene, Wertung, Steuerung und Chiptune-Audio-Verbesserungen.
- Backend-, Frontend- und Root-Version wurden von `0.4.0` auf `0.5.0` aktualisiert.

Verglichene Tags: `v0.4.0..v0.5.0`
